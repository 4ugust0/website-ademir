# Ademir | Consultoria Educacional

Site institucional em HTML, CSS e Bootstrap 5 para a Ademir Consultoria Educacional.

**Gestão que transforma. Estratégia que gera resultados.**

## Estrutura

```
index.html       Página principal
css/style.css    Estilos (paleta azul-marinho + dourado)
js/main.js       Animações, contadores e formulário
image.png        Logotipo (também usado como favicon)
img/             Coloque aqui a foto: img/ademir.jpg
```

## Personalização

- **Foto:** salve a foto do Ademir como `img/ademir.jpg`; ela aparece automaticamente na seção "Sobre".
- **WhatsApp:** troque `5500000000000` pelo número real nos links `wa.me` do `index.html`.
- **E-mail:** troque `contato@ademireducacao.com.br` no `index.html` e no `js/main.js`.
- **Redes sociais:** atualize os links `href="#"` da seção de contato.

## Como visualizar

Basta abrir o `index.html` no navegador.
