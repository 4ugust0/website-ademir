# Ademir | Consultoria Educacional

Site institucional em HTML, CSS e Bootstrap 5 para a Ademir Consultoria Educacional.

**Gestão que transforma. Estratégia que gera resultados.**

## Estrutura

```
index.html       Página principal
css/style.css    Estilos (paleta azul-marinho + dourado)
js/main.js       Animações, contadores e formulário
image.png        Logotipo (também usado como favicon)
img/             Coloque aqui a foto: img/ademir.jpg
```
